## 🔎 What This Document Covers

This document describes how Dracones Invictus at https://github.com/hmlendea/imperator-dracones-invictus manages personal data. It covers the application conduct and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

## 🏠 Self-Hosted Deployments

This project is a mod for Imperator: Rome distributed as static data files, namely Dacian culture definitions and English localisation text, that users install locally into the game's mod directory. The project maintainers do not operate a hosted service, do not receive data from installations, and do not obtain any data from players.

Instance operators, that is the players who install the mod, control their game installation, mod directory, local logs, save files, reserve copies, access controls, and the preservation or deletion of mod files. The project does not control those functions.

No data is sent from a self-hosted instance to the project maintainers or to external services. The mod contains no telemetry, update checks, crash reports, email, authentication, reverse-proxy, object-storage, or monitoring integrations, and it performs no network requests. No optional process exists, so operators have nothing to deactivate.

## 📥 Data We Handle

### Data Provided to the Application

- No personal data is requested, collected, or provided to the mod. The mod supplies only Dacian culture definitions and localisation text for Imperator: Rome.

### Data Generated or Collected by the Application

- No personal data is generated or collected automatically by the mod. The mod consists solely of static data files that the Imperator: Rome game engine reads during play.

### Data Received from Integrations

- No personal data is received from integrations or third parties. The mod has no network connectivity, no API integrations, and no external data sources.

## 🧭 Processing and Use

The application processes the data described above for these verified functions:
- None — the mod handles no personal data; it provides Dacian culture definitions and localisation text that the Imperator: Rome game engine reads locally

## 🗄️ Storage, Retention, and Deletion

The mod consists of static data files installed in the user's Imperator: Rome mod directory. The mod stores, retains, and deletes no personal data. Save files, logs, and configuration generated by the game are controlled by the game client and the player, not by the mod. Users uninstall the mod by deleting its files from the mod directory.

## 🔗 External Processing and Integrations

The mod has no built-in external data transfer and performs no network requests. The mod files are distributed through the Steam Workshop, Nexus Mods, and GitHub Releases; any account, download, or usage data handled by those platforms is governed by their own policies and is not received by the mod.

| Service or integration | Purpose | Data involved | Configuration or documentation |

## 🛡️ Data Protection and Security

The mod consists of static data files with no executable code, no network connectivity, and no personal-data processing. Its data-handling surface is therefore limited to the game files that the Imperator: Rome client reads from the local mod directory.

Operators remain responsible for updates, secrets, access controls, reserve copies, network exposure, and log protection on the machine that runs the game. No absolute security guarantee is made.

The original maintainers are not responsible for changes, modifications, or privacy issues introduced by downstream forks.
